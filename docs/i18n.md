# Content Localization (Roman Urdu + English)

ZnPedia do languages support karta hai: Roman Urdu (`ur`, default) aur English (`en`).

## Faisla: static locale routes, koi runtime cost nahi

| Option | Faida | Nuqsaan | Faisla |
| --- | --- | --- | --- |
| `app/[lang]` segment + `generateStaticParams` | Har language ka har page build par static HTML, hreflang ke liye alag URL | Routes ek folder neeche | **Chuna** |
| Proxy (middleware) se `Accept-Language` detection | Automatic language | Har request par code chalta hai | Nahi, switcher kaafi hai |
| Client-side translation (state se text badalna) | Ek URL | SEO mein English pages nahi, JS bundle bara, flash | Nahi |
| i18n library (next-intl waghera) | Bohat features | Dependency, setup | Abhi zaroorat nahi, sirf 2 locales |

Next.js official guide yahi pattern batati hai: [Internationalization](https://nextjs.org/docs/app/guides/internationalization).

## URLs

| Language | URL | `<html>` content `lang` | hreflang |
| --- | --- | --- | --- |
| Roman Urdu | `/ur/courses/javascript/closures` | `ur-Latn` | `ur` |
| English | `/en/courses/javascript/closures` | `en` | `en` |

`/` aur purane bina-prefix URLs (`/courses/...`, `/about`) `next.config.ts` ke redirects se `/ur/...` par jate hain. Yeh router config hai, proxy code nahi.

## Content files

```
content/courses/javascript/closures.mdx      Roman Urdu (source)
content/courses/javascript/closures.en.mdx   English
content/courses/javascript/meta.json         i18n.en.description
```

- English file na ho to page Roman Urdu content dikhata hai, upar "not translated yet" notice, `noindex`, aur canonical Roman Urdu page par.
- Content mein internal links `/courses/...` hi likhein. Renderer khud current language ka prefix lagata hai.
- `npm run check:content` dono files check karta hai aur English coverage batata hai.

## UI text

- `lib/i18n/dictionaries/ur.ts` aur `en.ts`. English dictionary ka type Roman Urdu wale se aata hai, is liye koi key choot jaye to typecheck fail hota hai.
- Dictionaries sirf server par load hoti hain. Client components ko sirf zaroori strings props mein milti hain.

## Nayi language add karna

1. `lib/i18n/config.ts` mein locale add karein.
2. `lib/i18n/dictionaries/<locale>.ts` banayein.
3. Chapters `<slug>.<locale>.mdx` aur `meta.json` mein `i18n.<locale>.description`.
