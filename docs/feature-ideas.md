# ZnPedia Feature Ideas

Content pehle add hua hai. Neeche wali list aage ke features ki hai. Har item ke saath level aur andaza.

## Pehle version mein ban chuke

- Docs search, `Cmd+K` / `Ctrl+K` ke saath (titles, keywords, descriptions)
- Active TOC highlight aur mobile par collapsible "On this page"
- Har chapter par level badge, reading time aur "Chapter n / total"
- Course overview pages (`/courses/<course>`)
- Heading anchor links
- 404, error, About, Privacy aur Terms pages
- Do languages: Roman Urdu (`/ur`) aur English (`/en`), switcher aur hreflang ke saath
