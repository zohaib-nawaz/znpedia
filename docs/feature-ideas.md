# ZnPedia Feature Ideas

Content pehle add hua hai. Yeh features abhi build nahi kiye, sirf list hain. Har item ke saath level aur andaza.

## Basic

| # | Feature | Kya karega | Effort |
| --- | --- | --- | --- |
| 1 | Docs search | Header ka disabled search box chalu, titles, headings aur keywords par client-side search (Pagefind ya FlexSearch) | M |
| 2 | Active TOC highlight | "On this page" mein current section highlight, scroll spy | S |
| 3 | Mobile TOC | Chhoti screens par collapsible "On this page" | S |
| 4 | Level badges | Har chapter par Beginner, Intermediate, Advanced badge aur reading time | S |
| 5 | Course landing page | `/courses/<course>` par redirect ki jagah overview: sections, chapters count, learning path | M |
| 6 | Edit on GitHub link | Har chapter ke neeche source file ka link | S |
| 7 | Copy heading link | Heading hover par `#` anchor copy | S |
| 8 | Custom 404 search | Not found page par related chapters suggest | S |

## Intermediate

| # | Feature | Kya karega | Effort |
| --- | --- | --- | --- |
| 9 | Progress tracking | Chapter "complete" mark, sidebar mein checkmarks, course progress bar (localStorage) | M |
| 10 | Bookmarks | Chapters save karna aur "My bookmarks" page | M |
| 11 | Quiz per chapter | Har chapter ke end par 3 se 5 MCQs, frontmatter se data | M |
| 12 | Live code playground | JS aur React examples browser mein run (Sandpack) | L |
| 13 | Prev/next keyboard shortcuts | Arrow keys ya `j` / `k` se chapters badalna | S |
| 14 | Command palette | `Cmd+K` se kisi bhi chapter par jump | M |
| 15 | Feedback widget | "Kya yeh page helpful tha?" yes/no, analytics ke saath | S |
| 16 | RSS / changelog | Naye chapters ka feed | S |

## Advanced

| # | Feature | Kya karega | Effort |
| --- | --- | --- | --- |
| 17 | User accounts | Login, cloud par progress aur bookmarks sync | L |

| 20 | Certificates | Course complete hone par quiz score ke saath certificate | L |
| 21 | Practice projects | Har section ke end par guided mini project | L |
| 22 | Interview prep mode | Sirf "Interview tip" sections aur quizzes ka ek collection | M |
| 23 | Spaced repetition | Revision cards jo din ke hisaab se wapas aayein | L |
