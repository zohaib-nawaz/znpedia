## 1. Fetch API kya hai?

<Callout variant="tip" title="Short definition">

**fetch() browser aur Node.js ka built-in function hai jo HTTP request bhejta hai aur Response ka promise return karta hai.**

</Callout>

Server se data lana (GET) ho ya data bhejna (POST, PUT, DELETE), modern JavaScript mein yeh kaam `fetch` karta hai. Purana `XMLHttpRequest` ab zaroorat nahi.

`fetch` do qadam mein kaam karta hai: pehle response headers aate hain, phir aap body ko `res.json()` ya `res.text()` se padhte hain. Dono promise dete hain.

## 2. Kyun zaroori hai?

Har real app ko server se baat karni padti hai: products load karna, login karna, form bhejna. `fetch` yeh sab ek simple promise based API se karta hai.

<CompareTable leftTitle="Purana XMLHttpRequest" rightTitle="fetch">

Events aur callbacks ka jaal | Promise, async await ke saath
Lamba setup code | Ek line mein request
JSON khud parse karo | res.json() method
Cancel karna mushkil | AbortController se cancel

</CompareTable>

## 3. Kahan use hota hai?

| Use case | Request |
| --- | --- |
| **Product list load** | `GET /api/products` |
| **Login / signup form** | `POST /api/login` JSON body ke saath |
| **Profile update** | `PATCH /api/users/1` |
| **Search as you type** | Purani request abort, nayi bhejo |
| **File upload** | `FormData` body ke saath `POST` |

## 4. Kaise kaam karta hai?

<Flow title="fetch ka flow">

fetch(url, options) call
↓
Request server ko jati hai
↓
Response headers aate hain, promise resolve
↓
res.ok check karo
↓
await res.json() se body padho

</Flow>

<Callout variant="important" title="Mental model">

**`fetch` sirf network fail hone par reject hota hai.** 404 ya 500 par bhi promise resolve hota hai, is liye `res.ok` khud check karna padta hai.

</Callout>

| Response property | Matlab |
| --- | --- |
| `res.ok` | Status 200 se 299 ke beech ho to `true` |
| `res.status` | Number, jaise `200`, `404`, `500` |
| `res.json()` | Body ko JSON parse karta hai (promise) |
| `res.headers.get(name)` | Koi header padhna |

## 5. Code example

### GET request with error check

```js
async function getPosts() {
  const res = await fetch("https://jsonplaceholder.typicode.com/posts?_limit=3");

  if (!res.ok) {
    throw new Error(`Request fail: ${res.status}`);
  }

  return res.json();
}

const posts = await getPosts();
console.log(posts.map((p) => p.title));
```

### POST JSON

```js
const res = await fetch("https://jsonplaceholder.typicode.com/posts", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ title: "Salam", userId: 1 }),
});

const created = await res.json();
console.log(res.status, created.id);
```

### Timeout aur cancel

```js
const controller = new AbortController();
const signal = AbortSignal.any([controller.signal, AbortSignal.timeout(5000)]);

cancelButton.addEventListener("click", () => controller.abort());

try {
  const res = await fetch("/api/search?q=js", { signal });
  console.log(await res.json());
} catch (error) {
  if (error.name === "TimeoutError") console.log("Bohot der lagi");
  else if (error.name === "AbortError") console.log("User ne cancel kiya");
  else throw error;
}
```

### Code kaise kaam kar raha hai?

| Line | Kya ho raha hai |
| --- | --- |
| `if (!res.ok) throw` | HTTP error ko asli error banaya |
| `method: "POST"` | Request ki qisam |
| `JSON.stringify(...)` | Object ko text body mein badla |
| `"Content-Type"` header | Server ko bataya ke body JSON hai |
| `AbortSignal.timeout(5000)` | 5 second baad khud abort, `TimeoutError` |
| `controller.abort()` | Manual cancel, `AbortError` |

## 6. Common mistakes

<Mistake
  title="res.ok check na karna"
  why="404 aur 500 par fetch reject nahi hota, error page ka HTML JSON samajh kar parse hota hai."
  better="Har response par if (!res.ok) throw new Error(...) lagayein."
/>

<Mistake
  title="res.json() ke aage await bhool jana"
  why="Data ki jagah pending Promise milta hai."
  better="const data = await res.json() likhein."
/>

<Mistake
  title="Object ko seedha body mein bhej dena"
  why="body: user likhne par server ko [object Object] text milta hai."
  better="JSON.stringify(user) aur Content-Type application/json header dein."
/>

<Mistake
  title="API keys frontend fetch mein likhna"
  why="Browser code har user dekh sakta hai, secret leak ho jata hai."
  better="Secret wali requests apne backend ya server route se bhejein."
/>

## Final quick revision

| Point | Detail |
| --- | --- |
| `fetch(url, options)` | Response ka promise |
| `res.ok` | HTTP success check, khud karna zaroori |
| `res.json()` | Body parse, `await` chahiye |
| POST | `method`, `headers`, `JSON.stringify` body |
| Cancel / timeout | `AbortController`, `AbortSignal.timeout` |

<Callout variant="important" title="Yaad rakhein">

`fetch` HTTP errors par reject **nahi** hota. Hamesha `res.ok` check karein aur lambi requests ke liye `signal` dein.

</Callout>
